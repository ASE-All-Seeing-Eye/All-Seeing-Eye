All Seeing Eye discovers network devices, reads their configuration over SSH
(strictly read-only) and analyzes it with security rules and an LLM.
Findings are shown in a dashboard and a report with prioritized recommendations. 

Diploma thesis at HTL Rennweg, 2026/27 - [allseeingeye.dev](https://allseeingeye.dev)
